# Krkr2Packer —— KrKr一键转直装包（吉里吉里2 galgame 一键转安卓）

把电脑上的 **Kirikiri2（吉里吉里2）引擎** galgame（文件夹里带 `.xp3` 文件的那种），
**一键打包成手机能直接安装的 APK**。

装到手机上点开图标就自动解压、自动进游戏——不用模拟器、不用选文件、不用敲命令行。

> 🤖 **AI 声明**：本项目从需求分析、代码编写、界面设计、素材处理、文档撰写，
> 到构建、测试辅助与发布上传，**全流程由 AI（GLM · ZCode 智能体）完成**；
> 人类只做了两件事——提需求，以及实机测试验收。
> Releases 里另有多个"仅美化"版本（夜樱主题 / 动效 / 看板娘），功能完全相同，按喜好取用。

## ✨ 特性

- 🖱 图形界面，全程鼠标点点点
- 🈶 支持中文路径、中文游戏名、中文应用名
- 🔁 自动换包名 / 应用名 / 入口钥匙 / 安装标记，多个游戏可共存互不干扰
- 📦 内置 apktool（首次使用自动下载），**无需安装安卓 SDK**
- 🔏 自动完成 v1 签名（安卓 5~14 实测可装）
- 🈳 模板壳瘦身白名单机制，引擎文件绝不会被游戏覆盖

## 📦 下载

到 [Releases](../../releases) 页面下载压缩包，解压即用（含全部依赖与模板壳）。

## 🚀 三步上手

1. 安装 [Python 3.10+](https://www.python.org/downloads/)（安装时勾选 **Add to PATH**）
2. 安装 [JDK 17+](https://adoptium.net)（推荐 Temurin，一路下一步）
3. 双击 **`启动打包工具.bat`**，然后：

```
选模板壳 → 选游戏目录 → 填包名和应用名 → 点【开始打包】→ 把产物 APK 传到手机安装
```

> 更详细的图文教程、模板壳自制方法、常见问题排查，见 [使用说明.md](使用说明.md)。

## 🧩 它是怎么工作的

1. 把一份"瘦身壳模板 APK"解包（模板 = Kirikiroid2 引擎删光游戏资源后的空壳）
2. 把你的游戏 `.xp3` 和相关文件塞进壳的 `assets/`
3. 重写入口钥匙 `recentpath.xml`，让引擎开机直接读你的游戏
4. 换包名 / 应用名 / 图标 / 安装标记，让多个游戏共存
5. 回编译 + 签名 → 得到可以安装的直装 APK

模板壳里藏着一个"机关"：Kirikiroid2 的文件选择按钮被放大到了全屏，
配合引擎启动时自动模拟点击，实现**打开即进游戏**。
